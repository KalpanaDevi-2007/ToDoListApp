# 📝 To-Do List App

A simple and user-friendly To-Do List Android application developed using Kotlin and Android Studio. This app helps users manage their daily tasks efficiently.

## 🚀 Features
- ➕ Add new tasks
- 🗑️ Delete tasks
- ✏️ Edit/update tasks
- 📋 Simple and clean user interface

## 🛠️ Built With
- Kotlin
- Android Studio
- XML (for UI design)

## 📱 How It Works
Users can add tasks to their list, update them when needed, and delete them once completed. The app is designed to be simple and easy to use for everyday task management.

## 📌 Future Improvements
- Add notifications/reminders
- Dark mode support
- Data storage using database
